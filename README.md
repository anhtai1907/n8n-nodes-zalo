# n8n-zalo

This is an n8n custom node for consuming the Zalo OA API. With this node, you can easily integrate Zalo into your n8n workflows and automate tasks such as sending messages, retrieving user information, and uploading files.

## Prerequisites
Before using this node, you'll need to obtain an app ID and OA access token from the Zalo Developer Platform. You can find more information on how to do this in the Zalo API documentation.

## Installation
Follow the [installation guide](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n community nodes documentation.
